You are the lead engineer for a new web game called **CASE** — a cinematic Arabic interactive detective/investigation game.

## 1. PRODUCT VISION

We are building a premium-feeling web experience where players investigate fictional cases.

A case contains:

* A crime/mystery scenario
* Several suspects
* Suspect statements and alibis
* Locations
* Evidence
* Timeline events
* Visual scenes
* A final accusation and solution

The player should feel like they are opening a real investigation file and solving a mystery, not playing a generic quiz.

The product will eventually support many cases, but in this phase we are building the **foundation only**.

---

# 2. ABSOLUTE PROJECT CONSTRAINTS

These constraints are mandatory:

### ZERO-COST / ZERO-API RULE

* Do NOT use any paid service.
* Do NOT use any external API.
* Do NOT use OpenAI, Gemini, Claude API, Firebase, Supabase, or any external backend.
* Do NOT use external AI services.
* Do NOT add authentication.
* Do NOT add payments.
* Do NOT add analytics services.
* Do NOT depend on remote data to make the application work.

The application must work entirely from the local codebase.

### DATA

Case data must be designed to come from local JSON/data modules.

Use mocked local data for the first demonstration case.

### STORAGE

Use localStorage only when persistence is necessary.

### IMPORTANT

Do not over-engineer.
Do not build features that were not requested.
Do not build a backend.
Do not create unnecessary abstractions.

---

The product is Arabic-first.
